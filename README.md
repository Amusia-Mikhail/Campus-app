# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/3dfc9d9c-8ca1-4f25-9c99-d37fb463f9b2

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and fill in your `GEMINI_API_KEY`, `SUPABASE_URL`/`SUPABASE_ANON_KEY`, and `VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY` values.
3. Run the app:
   `npm run dev`
